Workflow definitions

Definitions use the registered task types below. The validator checks the structure, module dependencies, step configuration, ordering, and agent assignments.

  • review_sources — summarize source retrieval status.
  • record_note — add a configured note to this project.
  • organize_corrections — summarize all categories or one A–F category.
  • manual_review — pause execution until a human records a review.

Available modules: projects; notes, sources, and corrections require projects; workflows requires projects; tasks requires projects and workflows; agent_coordination requires tasks.
